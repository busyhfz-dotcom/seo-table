# GitHub import notes

This directory captures the working SEOTable v0.2.0 reference implementation produced during the product redesign session.

It is intentionally stored under `prototype/` instead of replacing the repository's existing Next.js/worker monorepo. The production plan is to port validated behavior from this reference into the main architecture in controlled slices.

## Included in the source archive

- Bilingual Persian/English dark dashboard frontend
- FastAPI REST backend
- SQLite persistence reference schema
- Multi-page website SEO audit engine
- Safe auto-fix planning and approval queue
- Content opportunity model
- Website/Instagram/YouTube connector boundaries
- Docker configuration
- CI workflow reference
- Backend tests

## Intentionally excluded from Git history

Runtime databases, test databases, Python bytecode/cache files, browser screenshots and other generated runtime artifacts are not committed as loose files.
